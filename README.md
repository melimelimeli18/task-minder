# Task Minder

**Task Minder** adalah aplikasi manajemen tugas berbasis web yang dirancang untuk membantu pengguna mengatur tugas harian mereka secara efisien. Proyek ini dibangun dengan teknologi modern seperti PHP, Tailwind CSS, Vite, dan Svelte.

---

## Tech Stack

| Teknologi | Deskripsi |
|----------|-----------|
| <img src="https://upload.wikimedia.org/wikipedia/commons/2/27/PHP-logo.svg" alt="PHP Logo" height="20"/> **PHP (Vanilla)** | Digunakan untuk backend aplikasi tanpa framework tambahan. Menangani request dari form dan koneksi ke database. |
| <img src="https://cdn.jsdelivr.net/gh/devicons/devicon/icons/tailwindcss/tailwindcss-plain.svg" alt="Tailwind CSS Logo" height="20"/> **Tailwind CSS** | Framework CSS utility-first untuk styling yang cepat dan konsisten langsung di markup HTML. |
| <img src="https://vitejs.dev/logo.svg" alt="Vite Logo" height="20"/> **Vite** | Build tool modern untuk development yang cepat, mendukung Hot Module Replacement. |
| <img src="https://upload.wikimedia.org/wikipedia/commons/1/1b/Svelte_Logo.svg" alt="Svelte Logo" height="20"/> **Svelte** | Framework front-end yang mengkompilasi komponen ke JavaScript murni untuk performa yang tinggi. |
